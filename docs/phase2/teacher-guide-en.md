# Global Classroom Connect (GCC) — Teacher Pilot Guide
**Private Phase 2 pilot • For invited teachers only • November 2026**

Welcome! GCC helps verified teachers find international classroom partners and create exchange sessions. This pilot tests the experience **before** a wider Global Classroom Community launch.

**Open GCC:** https://gcc.pic-speak-story.com/#/teacher-access

## A. Join as a teacher
1. Choose **Create account**. Enter an email address you can access and a password of at least eight characters.
2. If asked, confirm the link in your email. Return to GCC and **Sign in**.
3. Complete your teacher-and-school application, including your school, country, school time zone and a clear face photograph. School website is optional.
4. Choose **Submit for approval**. A GCC administrator must verify the application before Teacher Space is available.

If a registration attempt says **Failed to fetch**, avoid rapid repeated submissions. Check your email, try a different network or browser, and tell your pilot coordinator the approximate local time and device/browser. **Never share your password or confirmation code.**

## B. Choose ONE of the two starting points after approval

### I want to HOST → Create a Session
1. Open **Teacher Home → Create a Session**.
2. Optionally select a Cultural Exchange, Language Exchange or SDG starter. It fills a title/theme you can edit; it does not publish automatically.
3. Set a future date and time **in your school's own time zone**; choose participating age/school levels, host-school student count, **maximum total capacity including your own students**, and exchange format.
4. Review the session and choose **Publish**. During testing, put **[PILOT]** at the beginning of a test session title so it is recognizable to other approved teachers.
5. Open **Join Requests / Notifications** in GCC to check applications. **Automatic email notification to hosts is not available in the current release.**
6. Approve or decline each request after checking it. Do not approve more students than the session capacity.

### I want to JOIN → Find a Partner
1. Open **Teacher Home → Find a Partner**.
2. Search by available hours in your school's time zone or by country; additional filters are optional.
3. Open a session to check the details, select **Request Join**, enter the number of participating students and an optional short note.
4. Review **Join Requests / Notifications** for the host's decision. If no matching session appears, clear or adjust search filters.

**Find a Partner and Create a Session are intentionally separate screens.**

## C. After a host approves
GCC can export session dates to Google, Outlook or Apple Calendar. The current pilot version **does not include built-in chat, guaranteed private contact exchange, or automated host-request email notifications**. To arrange a call, use a contact method that both teachers consent to (e.g. school email, WhatsApp, LINE or Messenger); your pilot coordinator can help connect you privately when needed. Public Teacher Network profiles only show details a teacher has chosen to publish.

## D. Safe testing
- Do not enter real student names, identifiable student photographs, private meeting URLs, passwords or contact phone numbers into public session descriptions.
- For a **test** session, use non-identifying student counts and an agreed test schedule. Close/withdraw test sessions when testing ends.
- Please do not post screenshots with names, email addresses, personal contact details, or student data in public GitHub issues.
- Report problems privately to the pilot coordinator with: pilot ID, device and browser, action attempted, approximate local date/time, what happened, and a redacted screenshot if useful.
